# Number-guessing-game-using-node.js

## How to Play

This command-line game chooses a random whole number from 1 to 100. Enter guesses when prompted. After each incorrect guess, the game tells you whether your guess was too high or too low. When you guess correctly, it prints how many valid guesses you made.

Guesses must be whole numbers from 1 to 100. Invalid entries do not count toward your attempts.

## Run the Game

Install [Node.js](https://nodejs.org/) if it is not already installed, then run this command from the project folder:

```bash
node index.js
```

The game uses Node.js's built-in `readline` module and does not require additional packages.
